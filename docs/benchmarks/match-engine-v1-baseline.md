# Pitch Match Engine v1 Baseline

> Reproducible T0 snapshot generated by `npm run balance:match`. This report is diagnostic only and is not imported by the live game.

**Baseline commit:** `00b92cf34f9385933fa5b3f8eeca0b76cf2229ef`

**Report version:** 1

**Simulation contract:** P2 aggregate-phase engine before Attribute-to-Tactics Causality 2.0

**Samples:** 600 neutral matches + 300 paired seeds per matchup (3000 simulations total)

**Equal-team rating:** 77

## Reproduce

- Print the report: `npm run balance:match`
- Verify the committed snapshot: `npm run balance:match:check`
- Intentionally refresh it after an approved engine change: `npm run balance:match:update`

The same explicit seed starts each control/variant pair. The current engine consumes extra random values after some branch outcomes (for example a goal choosing a scorer and possible assist), so T0 pairs the initial stream rather than claiming a fixed per-action RNG packet. T3 owns that stronger contract.

### Matchup definitions

- **Direct counter vs high line:** variant (buildUp=direct, tempo=fast, transition=counter); opponent (defensiveLine=high, defensiveApproach=front_foot). Captures the current generic space-behind-the-line modifier.
- **Aggressive press vs patient build-up:** variant (tempo=fast, defensiveLine=high, pressing=aggressive, defensiveApproach=front_foot); opponent (buildUp=patient, transition=hold_shape, chanceCreation=work_ball). Captures territory gains alongside cards, fitness and late-defence costs.
- **Wide delivery vs narrow block:** variant (tempo=fast, width=wide, chanceCreation=early_delivery); opponent (defensiveLine=low, width=narrow, defensiveApproach=compact). Captures the current wide route counter to a narrow defence.
- **Work ball vs balanced block:** variant (buildUp=patient, tempo=slow, transition=hold_shape, chanceCreation=work_ball); opponent (balanced defaults). Captures the current possession and shot-volume trade-off.
